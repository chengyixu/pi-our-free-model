# Changelog

## 0.1.0

- Pi-native public Kilo free-pool discovery and streaming.
- Optional authorized-key OpenCode Zen route; no anonymous-client impersonation.
- `/free-models` selector, exact-ID commands, refresh and privacy disclosure.
- Pi-owned persistent catalog, offline startup and normal session usage accounting.
- Instrumentation, native tools/results, reasoning mapping, cancellation and wrong-header SSE handling.
- Hermetic HTTP/API and real-Pi CLI tests; Linux/macOS, Node 22.19/24 CI.
- English/Chinese documentation and original vector/PNG launch assets.

This release intentionally does not port DSH desktop EAC/account channels, web dashboards, automatic probing, proxy subscriptions or LAN forwarding.
